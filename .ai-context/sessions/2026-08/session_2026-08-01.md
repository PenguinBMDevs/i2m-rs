## 任务：将 ImageToMidi_Modded 完整逻辑移植为 i2m-rs lib + CLI example

- **日期**：2026-08-01
- **涉及文件**：新增约 28 个 `.rs` 文件，覆盖 lib、image/resize/cluster/midi 子模块、tests、examples
- **关键决策**：
  - 使用 `midly 0.5.3` 负责 MIDI 读写，复刻 C# `ColorEvent` 的 `0xFF 0x0A ...` payload。
  - 图像 buffer 统一为 BGRA（与 C# 一致），`alpha < 128` 视为透明。
  - 保留 C# 核心转换语义：从图像底部向上扫描，行即 tick，颜色即 track，列映射到 MIDI key。
  - 颜色量化支持 RGB/HSV/HSL/Lab/CIEDE2000；调色板生成覆盖 KMeans、KMeans++、Popularity、Octree、VarianceSplit、PCA、Max-Min、NativeKMeans、MeanShift、DBSCAN、OPTICS、GMM、Hierarchical、Spectral、LabKMeans、Floyd-Steinberg/Ordered dither、FixedBitPalette。
  - Resize 实现 11 种算法（AreaResampling、Bilinear、NearestNeighbor、Bicubic、Lanczos、Gaussian、Mitchell、BoxFilter、IntegralImage、ModePooling、Hermite）。
  - 文件全部控制在 400 行以内，函数尽量小于 50 行。
- **依赖关系**：
  - `image` 负责 raster 解码，`resvg/usvg/tiny-skia` 负责 SVG 渲染。
  - `rand`/`rayon` 用于聚类采样与并行（并行暂未全部接入）。
  - `thiserror` 统一错误类型。
- **注意事项**：
  - `OnlyWpfMedianCut` 在 Rust 无对应实现，回退到 KMeans++。
  - OPTICS 在 `PaletteSource` 中已保留，但实现回退到 DBSCAN。
  - FixedBitPalette 未暴露灰度开关（按 C# 默认非灰度处理）。
  - 未实现 FFmpeg/Ghostscript 外部命令包装，当前仅支持单帧图像输入；视频/GIF 多帧留待后续扩展。

  - `cargo clippy --all-targets -- -D warnings` 0 warnings
